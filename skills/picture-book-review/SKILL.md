# Picture Book Post-Class Review (课后评价 · 极简无名版)

给家长的简短课后评价，从备课稿产出。**不绑定学生**，一律无名通用版。

## 触发
- 主要由 picture-book-prep 在备课时同步生成，无需单独跑。

## 输入
- `lessons/<书名>.md`：取书名(H1)、关键词(`` `vocab` `` 标记 + 题中复用词)、故事梗概。
- `config-review.md` 的 `notes`（可选）：不填就用通用收尾；填了也只做一两个词的微调，不展开。

## 输出
`reviews/review-<slug>.md`（slug=书名小写连字符）。`present_files`。打印一行确认。

## 流程

### 1. 读备稿
读指定 `lessons/<书名>.md`，取书名 / 关键词 / 梗概。

### 2. 输出格式（一整段，三句，无标题无分段）

```
本节课我们阅读了《XXX》，一个{一句故事概括}的故事。重点单词回顾：{英文 中文，英文 中文，…}。整节课宝贝很认真，非常棒，继续加油！
```

三句固定顺序：
1. 主题引入：「本节课我们阅读了《XXX》，一个{一句故事概括}的故事。」句末直接结束。
2. 重点单词回顾：「重点单词回顾：英文 中文，英文 中文，…」（8–15 词，简洁中文释义，全用中文逗号）。
3. 一句鼓励：「整节课宝贝很认真，非常棒，继续加油！」
