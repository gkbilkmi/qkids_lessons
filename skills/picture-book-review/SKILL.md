# Picture Book Post-Class Review (课后评价 · 通用无名版)

生成温暖、给家长看的课后评价，从课堂笔记 + 备课稿产出。**不绑定学生**，评价一律无名通用版。

## 触发
- 「写评价 / 点评 / 课后评价 <lessons/xxx.md>」→ 重跑（课前草稿已由 prep 自动生成，此命令仅用于按 notes 轻度改写表现块）。
- 主要由 picture-book-prep 在备课时同步生成，无需单独跑。

## 输入
- `config-review.md` 的 `notes`（可选）：填了可轻度改写 Block3，不填用通用模板。
- `lessons/<书名>.md`：取书名(H1)、关键词(`` `vocab` `` 标记 + 题中复用词)、故事梗概。

## 输出
`reviews/review-<slug>.md`（slug=书名小写连字符）。`present_files`。打印一行确认。

## 流程

### 1. 读备稿 + notes
- 读 `config-review.md` 的 `notes`（表现真相来源，可选）。
- 读指定 `lessons/<书名>.md`，取书名 / 关键词 / 梗概。

### 2. 输出格式（单块连续文本，无标题无分段）
输出为一整段纯文本，五块内容按顺序自然衔接，不加 `##` 标题、不分段、方便一整块复制。

内容顺序：
1. 主题引入：「本节课我们阅读了《XXX》，一个{一句故事概括}的故事。」
2. 重点单词回顾：「重点单词回顾：中文 英文，中文 英文，…」（8–15 词，简洁中文释义）
3. 课堂表现：只写真实能力点和观察，不用套话。参考句式：「宝贝今天……，能……（具体能力）……。」（若 notes 有真实观察则按笔记改写）
4. 针对性复习建议：「课下你可以和宝贝……，巩固……句型。也可以用……，相信……喔。」（具体、可操作、第二人称）
5. 鼓励结尾：一句温暖鼓励，嵌入学习主题，"继续加油！"结尾。

### 3. 风格
- 温暖真诚如和家长聊天；评级词自然嵌入句子，不列表/表格。
- 表扬优先，待提升项正向表达（"可以多…" / "建议…"）。
- 词表"英文 中文"对；全文 150–250 字（不含词表）。
- 不重复：词表已列的词最多再提一次（仅 Block4）；"多读几遍"至多出现两次。
- 无拼音；除非 notes 风格用 emoji，否则不用。

## 自检
- ☐ 五块齐全顺序对：主题 → 词表 → 表现(通用两句) → 建议 → 结尾。
- ☐ Block1 止于"{故事概括}的故事。"无尾部从句；**全局无名**（"我们" / "宝贝"）。
- ☐ 词表"英文 中文"，来自备稿；建议具体；150–250 字。
- ☐ Block3 通用两句；notes 在则按"能{能力点}"风格改写仍两句。
