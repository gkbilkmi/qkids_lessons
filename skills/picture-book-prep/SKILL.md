# Picture Book Lesson Prep（通用版 · 按级别）

读 pics/ 绘本截图，按级别生成 `lessons/<书名>.md` 备课稿，并同步生成 `reviews/review-<slug>.md` 评价草稿。**不绑定任何学生**，难度完全由 book_level 决定。

## 触发
- 用户说「备课」「备课 <级别>[时长]」「备课 <书名>」，例如「备课」「备课 C」「备课 G级别25min」「备课 H」。
- **级别自动定位**：读封面书名 → 查 `级别书单-书名级别对照.md` 匹配 → 命中则自动用该级别；未命中才问用户。
- 时长缺省按 25 分钟。
- 若用户指令直接给了级别（如「备课 C」），跳过书名查表，直接用该级别。

## 输入
- `pics/`：Glob 排序，第一张=封面，其余=页面 2..N，`N`=文件总数。
- 级别：优先从用户指令解析；未给则从封面书名查 `级别书单-书名级别对照.md` 自动定位。
- 读图：**先用 Read 逐张读图**（优先，最准：书名/插画/UI 都准）。仅当 Read 报错（"model does not support images"）才降级 `tesseract`(eng) OCR 兜底——**不要预先跑 OCR**；**绝不凭 OCR 臆造插画内容**（角色/颜色/动作），封面书名读不出则问用户。
- `级别书单-书名级别对照.md`：书名→级别对照表（378本，AA–K级），按书名精确匹配。
- `AA-K级别-index.md`：共享备课稿书名索引（级别 + 书名 + 起始页）。
- `AA-K级别.txt`：939 页共享备课稿全文，`===== PAGE N =====` 分页标记。命中 index 后按页码截取对应书的内容作为参考素材。

## 输出
`lessons/<书名>.md`（书名按封面原样保留大小写空格，如 `My Sister.md`）。存后 `present_files`。

## 流程

### 0. 确定目标文件夹 + 去重
- **指令含数字**（如 `备课 1`）→ 直接用 `pics-<n>/`。
- **指令不含数字** → 运行 `python3 check_latest_pics.py`，按输出自动选择最新图片所在的文件夹。
- 对目标文件夹执行 `python3 dedup_pics.py <pics_folder>`，删除重复截图（平均像素差 < 8.0 视为同页）。
- 去重后再进入步骤 1 读图，确保 `N`=去重后的唯一页数。

### 1. 读图
- Glob 排序 pics，`N`=总数。留意平台页码（如 `Reset x/y`）：若 `y`>截图数，按平台实际总页数编号并提示缺哪页，缺页题仅从可见文字出，不臆造插画。
- 读每张图：封面取书名 + 一句话梗概；每页取英文文字 + 简短插画注记。封面书名读不出 → 先问用户再生成。

### 1b. 查共享备课稿（命中则取参考素材）
- 拿到封面书名后，在 `AA-K级别-index.md` 中**精确匹配**（忽略大小写与标点，如 `All about me` 命中 `All about me`）。
- **命中**：记下起始页码，从 `AA-K级别.txt` 截取该书内容（从起始页到下一本书起始页之间的所有内容），作为**参考素材**带入步骤 4 的生成。参考素材用于校准题型、词汇、语言知识点附录，不直接复制输出。
- **未命中**：跳过，按原流程从零生成。

### 2. 题量
- 每内容页 **2–3 题** + 封面 1 题。

### 3. 难度校准（按 book_level）
- **A（≈5–6岁）**：极简句，what/where，具体名词。
- **B（≈7–8岁）**：加 how/why，简单形容词，现在时。
- **C（≈9–10岁）**：why/how 一步推理、比较级、轻推断、感受。
- **D+（≈11+岁）**：抽象推理、延伸。
- **H 及以上（H+）→ 走 H+ 讨论模式（3b）。**

### 3b. H+ 讨论模式（book_level ≥ H）
- 少考"是什么"，多讨论 / 比较 / 跨文化延伸；先提问让学生产出，知识类可老师先给背景。
- 可写 `Teacher:` / `Student:` 对话或 `#### 💬` 编号提示；答案 1–3 句带推理。
- **允许中文教师侧注释**（如 `pray 祈祷`、`hijab 头巾`），仅作老师旁白，不进学生答案。

### 3c. 听说型（任意级别）
用户指令注明「听说型（能说不会读）」时：
- 用 H+ 讨论风格式出题（开放、生活、观点），题量 3–4/页。
- 不安排认读：所有词靠老师读出，学生口头解释/造句/举例。
- 在 `## 🔑 Key Words` 下加一行 `> 由老师读出目标词，学生口头回应，不安排认读`。
- 保留基础结构。

### 4. 逐页生成
**若有步骤 1b 的参考素材**：以图片内容为主体，参考素材用于校准题型难度、词汇选取、语言知识点附录的覆盖度。图片与参考冲突时以图片为准（版本可能不同）。
封面（H1 下、不编号）：
```
# 《Book Title》
#### 💬 "Look at the cover. …"
**A:** "…"
```
内容页：
```
### (X/N) `vocab`           ← 单词/短语
### (X/N) *adj-adj-adj*     ← 语法/句式（比较级、词族）
```
无关键词则 `### (X/N)`。下接 `#### 💬` 编号题 + 加粗 **A:**。

规则：
- 每题以 why/what/how/when/where 起（H+ 放宽）；yes/no+推理也可。跨页轮换起手词。
- 每 2–3 页至少 1 道 `(推断性)` 题。
- **绝不问作者/插画者/who wrote this**；推断题用"故事想告诉我们什么"而非"作者想告诉我们什么"。
- **每页必带个人生活延伸**（所有级别）：把当页内容桥接到孩子自身——动物→"你最喜欢什么动物/有宠物吗"；食物→"你喜欢…吗"；家人→"你家有几口人"；活动→"你喜欢…吗/什么时候…"；感受→"你什么时候觉得开心"。一句即可，但必须在。
- 每题都给 **A:** 答案（多解用 `/` 隔开，如 `**A:** "A basket / Gloves."`）。
- 词汇高亮：单词反引号 `` `vocab` ``，句式/词族斜体 `*big-bigger-biggest*`；vocab 页首题用该词。
- 语气：口语化、温暖如真人老师 Read-Aloud。要点：①一句一问，不塞多个疑问；②不用嵌套/翻译腔；③用真实引导语（Look here… / Check this out…）；④答案像孩子真话。无中文/拼音（H+ 中文旁白除外）。避免考试腔（"Why or why not?" 等）。

### 5. 组装 + 语言知识点附录
```
# 《Book Title》
#### 💬 封面预测题
**A:** …
---
### (2/N) `vocab1`
#### 💬
1. "…"  **A:** "…"
2. "…"  **A:** "…"
---
… 
### (N/N) `vocabN`
#### 💬
…
---
## 📚 语言知识点
### 一、词组、固定搭配
1. `knock on the door` 敲门
### 二、语法知识点
1. 一般现在时 — 例词/例句（取书中原句）
### 三、故事内容提问
1. What happens at the start?  **A:** …
```
- 标题《…》H1；封面不编号；页码 `2/N`…`N/N`，分母=文件总数；页间 `---`。
- **`## 📚 语言知识点` 为必附块**（仅此块可用中文）：三部分——词组搭配 / 语法 / 故事内容提问（4–6 道，含英文 **A:**）。供老师速查，不念给孩子。
- 格式细节以本 SKILL.md 步骤 4 的规则为准。

### 6. 保存（含同名冲突检查）
- 存 `lessons/<书名>.md`。若已存在 → 直接覆盖（通用稿，同书即同稿；提示替换了旧稿）。
- 不同书同名 → 绝不覆盖，问区分文件名。
- 打印一行确认：路径 + 页数 + 总题数。

### 7. 同步写评价草稿（课前）
存备课稿后立即写 `reviews/review-<slug>.md`（slug=书名小写连字符），走 picture-book-review 的 5 块结构，课前调整：
- Block1：「本节课我们阅读了《XXX》，一个{故事概括}的故事。」（"一个…的故事"，无尾部从句）。
- Block2 词表 + Block4 建议来自备课稿关键词。
- Block3 通用两句话（课前无笔记）。
- 评价一律无名通用版（Block1 "我们"，Block3 "整节课宝贝…"）。
- 两文件一起 `present_files`。

## 自检（保存前）
- ☐ 标题《…》；封面不编号有 1 预测题 + **A:**。
- ☐ 每内容页 `### (X/N)` 编号 `2/N`→`N/N`；`#### 💬` 编号 Q + 加粗 **A:**。
- ☐ 每 2–3 页 ≥1 `(推断性)`；每页有个人延伸。
- ☐ 末尾必附 `## 📚 语言知识点` 三部分全（词组搭配 / 语法 / 故事内容提问）。
- ☐ 若步骤 1b 命中 index：参考素材已用于校准题型/词汇/附录；图片与参考冲突处以图片为准。
