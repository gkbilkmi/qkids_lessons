# qkids 备课工作区 — 长期约定

## 工作区布局
- `books/` — 绘本截图，每个子文件夹=一本书（`page-01-of-NN.png`，第一张=封面）；备课先按封面识别书名，再查 `lessons/` 是否已有，缺的才补备。旧 `pics-<n>/` 仍兼容。
- `students/` — **已于 2026-10-15 删除**（用户决定备课改为纯按级别通用，不再用学生档案）。
- `config-review.md` — 课后评价草稿区，只保留 `notes` 字段（每次上课后改写这一两句话）。
- `lessons/` — 备课稿，文件名直接用绘本书名（如 `My Sister.md`、`So Big!.md`），不用 `lesson-` 前缀。
- `reviews/` — 课后评价（如 `review-bug-on-a-rug.md`）。

## 学生档案格式（已废弃 · 2026-10-15 删除）
- `students/` 目录及全部学生档案已删除。备课改为**纯按级别通用**，难度只由 `book_level` 决定，不再解析任何学生档案。下方为历史格式，仅供追溯：
  - `student_age` / `lesson_minutes` / `book_level` / `student_gender` / `pics_folder`（5 字段，旧格式）

## config-review.md（课后评价草稿区，可选）
- 只保留 `notes`：本课课堂概要（学生表现、需关注的单词/句子、整句输出情况等）。**课前评价已自动生成（通用两句话表现），此 notes 仅用于课后轻度改写表现块**，不填也能出评价。

## 触发方式（给学生的指令）
- 备课（**通用·按级别**，2026-10-15 起不再用学生档案）：「备课 <级别>[时长]」（如「备课 C」「备课 G级别25min」「备课 H」）→ picture-book-prep 按 `book_level` 生成 `lessons/<书名>.md`，并**同步生成** `reviews/review-<slug>.md` 无名通用评价草稿。级别必填、时长默认 25min；若用户带学生名则忽略名字、只取级别。
- 写评价（可选重跑）：「写评价 <绘本md>」→ picture-book-review 重跑评价（纯通用无名，不解析学生）；课前已自动生成，此命令仅用于按 config-review.md 的 notes 轻度改写表现块。
- 评价自 2026-10-09 起全面无名通用版（Block1 "本节课我们阅读了…"，Block3 "整节课宝贝…"），与 daily-prep-check 一致。

## 定级课（H–K 连堂）备课约定（2026-10-14）
- 定级课 = **同一节课连上 H/I/J/K 四本绘本**，不单独拆课；备课稿**合在一个 md**：`lessons/定级课H-K备课稿.md`（不要按书拆成多文件）。
- 问题组织：按「词义推断 / 画面观察 / 生活关联 / 批判思考」四类，每题前加 `[中文小标签]`（H+ 允许老师侧中文）；推理/批判类标 `(推断性)`；页面编号沿用绘本原页码，缺失页在稿头注明。
- 措辞禁忌：**"What's the moral of this story?" 等抽象主题问法太深奥**（用户 2026-10-14 反馈），改成孩子能接的个人化问法（如 "would you rather be the fast bird or the steady bird — and why?"）。
- 定级课目前不出课后评价草稿；用户要时按无名通用版。

## 备课 Skill
- 名称：`picture-book-prep`（user-level，路径 `~/.workbuddy/skills/picture-book-prep/`）
- 触发：用户说"备课/备一下 <级别>[时长]"（如「备课 C」「备课 G级别25min」「备课 H」），pics/ 就位。级别必填、时长默认 25min；带学生名则忽略名字只取级别。
- 输出：写入 `lessons/<书名>.md`（文件名直接用封面书名，保留大小写与空格；无 `lesson-` 前缀）。
- **同步输出**：备课完成后立即写 `reviews/review-<slug>.md` 评价草稿（开头"一个…的故事"、通用两句话表现、单词表+复习建议来自备课稿），并一并与备课稿 present。
- 输出格式：参见 `references/lesson-style-example.md`（《Blackberries》样本）。
- 题量：每内容页 2–3 题 + 封面 1 题；why/what/how/when/where 轮换；按 book_level 卡词汇上限。
- 标记：`(推断性)` 推断题；`**A:**` 答案加粗；`---` 分页；`### (X/N)` 中 N = pics 文件总数。
- 禁忌：**不得出"作者是谁 / who wrote this book / 插画者"等作者题**；推断题用"故事想告诉我们什么"而非"作者想告诉我们什么"。

## 级别校准（重要，2026-10-14）
- **book_level ≥ H（H/I/J/K）→ 走 H+ 讨论式**，单册书也一样（不限定级课）：减少"照搬原文"记忆题，改讨论 / 比较 / 跨文化延伸；每题前 `_[中文小标签]_`（词义推断 / 画面观察 / 生活关联 / 批判思考 / 词汇拓展 / 语法感知 / 文化对比），教师侧可用中文注释（如 `curds 凝乳`、`芝士奶盖`），推理 / 假设类仍标 `(推断性)`，答案给 1–3 句完整示范。参考样本 `~/.workbuddy/skills/picture-book-prep/references/lesson-style-example-H.md`。**A–G 级别仍走基础记忆式**。
- H+ 画面观察 / 事实类问题**先提问让学生观察产出**，不要老师先罗列答案（如"页面上有哪些动物 / 工厂里牛奶怎么变"先问学生说，而非老师一口气报完再问）；知识讲解 / 定义类可老师先给背景再讨论。
- 判定依据仅 `book_level`（学生档案已删除，无 student_age）；用户若把高级别书口误说成低级别（如 J 说成 G），以封面/内容实际难度为准再动手。
- **页码分母 = `pics/` 文件总数**；中途补插的页面只要文件名数字落在正确位置，排序后会自动落到对应页位（`Say Cheese` 补页即自动成为 (4/9)）。平台翻页若分两组（如 1/5–5/5 与 1/4–4/4），在稿头注明即可，正文仍按文件顺序编号。

## 课后评价 Skill（备课同步生成）
- 名称：`picture-book-review`（user-level，路径 `~/.workbuddy/skills/picture-book-review/`）
- 触发：主要由 picture-book-prep 在备课时**同步生成**（纯通用无名）；也可单独"写评价/点评 <绘本md>"重跑。
- 流程：读 lessons/ 备课稿 md（书名/单词/故事）→ 生成**纯通用无名**评价；`config-review.md` 的 notes 可选，仅作微调。
- 结构（**极简 3 句，2026-10-20 起**）：主题引入 → 重点单词回顾（英文 中文，8–15 词）→ 一句鼓励「整节课宝贝很投入，非常棒，继续加油！」。**不再写课堂表现细节、能力点、复习建议、下节课期待。**
- 开头句式："本节课我们阅读了《书名》，**一个**{故事概括}的故事。"（用"一个…的故事"；**句末不带"我们一起学习了很多有趣的内容"等尾部从句**，2026-09-12 用户明确去掉）。
- 全文约 80-120 字，一整段无标题无分段；参考 `references/evaluation-style-example.md`。
- 风格：温暖、给家长看、只夸一句。
- **称呼规则（已废弃）**：2026-10-15 起学生档案删除、评价彻底无名通用版（Block1 "我们" / Block3 "宝贝"），不再按年龄区分称呼。
- **2026-10-09 起评价全面去名字（全局）**：无论备课是否绑定学生名（"备课 Koko" 或 "备课 G级别25min"），评价一律无名通用版——Block 1 "本节课我们阅读了…"（绝不用"{称呼}阅读了"），Block 3 "整节课宝贝…"。学生名仅用于解析档案做年龄/级别校准，不进评价文本。
- **用户措辞偏好（2026-09-11 用户对 Moon 评价的手改稿）**：
  - 复习建议/结尾用**第二人称「你」+ 语气词「喔」**，鼓励式收尾："后面跟着绘本一点点积累，相信你的词汇量经过日积月累会越来越丰富喔。"
  - Block 3 第二句优先写**能力点**（如"可以跟着老师举一反三尝试进行造句"），而非只描述状态（如"语调自然、听上去舒服"）。
  - 待提升项一律正向表达，不写"需要纠正/不足"，改成"可以……/相信你会……"。

## 课表查稿 Skill
- 名称：`daily-prep-check`（user-level，`~/.workbuddy/skills/daily-prep-check/`）
- 触发：用户发课表截图或说"今天的课/查课"。流程：截图提取书名（去掉"级别 - 序号."前缀，保留大小写标点）→ lessons/ 宽容匹配（不分大小写、忽略标点）→ 报告"已有备课稿 / 需要新备课"→ 已有稿的书各写一份 `reviews/review-<slug>.md` 通用版评价。评价格式约定（2026-10-08）：**「宝贝」仅出现在 Block 3"整节课宝贝……"一句**，Block 1 用"本节课我们阅读了…"，标题不放"宝贝"；其余沿用 picture-book-review 5 块结构（复习建议用"你"+"喔"）。旧版绑定学生名的同名评价文件按要求覆盖为通用版。

## 图片内容提取
- **首选**：直接用 Read 工具读图（本会话模型可看图，绘本截图、互动课件界面都能直接读，文字/插画/界面元素都准）。
- **兜底**：当 Read 不可用或图片含大量装饰性 UI（如 Qkids 互动课件的 Preview/Reset 控件）时，用 `tesseract`(eng, /usr/local/bin/tesseract) OCR 辅助；小字/书名识别失败时先用 `sips -Z 2400 in.PNG --out out.png` 放大再 OCR，或裁剪顶部。
- 已识别的绘本书名无需写进学生档案（档案只有上述 5 个字段）；试听课可在 `config-prep.md` 设 `book_title` 跳过 OCR，常驻学生直接靠封面图识别。
