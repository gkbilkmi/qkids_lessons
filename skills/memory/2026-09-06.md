## 🔑 关键修正：窗口截图坐标映射（14:39 发现，务必沿用）
- `screencapture -l<wid>` **默认带窗口阴影**，图像尺寸会变大且**长宽比例失真**（例：窗口 1200x672 → 图 2536x1480，x/y 缩放比 2.113 vs 2.202 不一致），导致算出的点击坐标**系统性偏移 20~30px**，点不中。
- **正确做法**：`screencapture -l<wid> -o`（`-o` = 去阴影）。此时图像 = 窗口的精确 2 倍（1200x672 → 2400x1344）。
- **映射公式**：`screen_x = 窗口bounds.x + 图像x / 2.0`，`screen_y = 窗口bounds.y + 图像y / 2.0`
- 优点：不受其他窗口遮挡影响（比全屏截图可靠），且坐标精确。
- 校验：用 `-o` 算出 进入教室 = (1398,808)，与全屏截图法 (1399,807) 一致 ✓
